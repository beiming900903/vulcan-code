# AI 管理知识库

## 权威与同步条件

本文说明人工生命周期、AI 内容写入及两端展示的共同边界。实际字段、格式与数值约束以当前源码为准：

- `crates/vulcan-workspace-store/src/knowledge_base/models.rs`：当前实体、历史、索引、套件及边界常量。
- `crates/vulcan-workspace-store/src/knowledge_base/runtime/`：事务、实时授权、历史还原、索引与工作者。
- `crates/vulcan-service-api/src/knowledge_base.rs`：封闭人工请求；响应由存储类型定义。
- `crates/vulcan-service-kernel/src/knowledge_base_services.rs` 及其子模块：宿主生命周期与冻结嵌入路由。
- `crates/vulcan-service-kernel/src/rpc_dispatch/knowledge_base.rs`：当前 RPC 注册目录。
- `crates/vulcan-agent-runtime/src/tooling/native/knowledge_base.rs` 及其子模块：四工具参数、执行与结果。
- `apps/vulcan-code-web/src/service/knowledge-base-service.ts`：WebUI 调用；TUI 一对一镜像。

修改上述类型、常量、工具暴露链、RPC、持久格式或页面行为时同步本文与行为测试；本文不建立第二套 Schema。

## 人工与 AI 边界

人工创建空库时必须选择索引模式，填写名称与用途；含向量的模式必须明确选择可用后台嵌入路由和维度。
人工可修改名称、用途及索引模式，管理项目授权、默认启用、会话库集合与自定义词典，查看当前内容和永久历史，
确认还原、补生成失败向量、导入导出套件、删除整库。WebUI 与 TUI 不提供文档或目录内容编辑、外部目录同步、
来源目录重映射、忽略文件或整理库控件。

AI 使用 `knowledge_list`、`knowledge_read`、`knowledge_search`、`knowledge_write` 有意识管理结构化长期资料。
这些资料不属于自动萃取和衰减的 VMM，也不是工作区文件。用途说明指导写入目标；写入前先了解库内结构。
正文、目录说明、摘要、关键词、向量收录策略及来源观测均由 AI 内容动作管理。

## 持久格式与原子变更

每库当前格式为 2，套件为 3；不读取、不迁移、不降级旧格式。错误或旧格式库在注册表中保留英文诊断，
两端只允许查看原因和删除。会话元数据及子执行配置按 [会话元数据](session-metadata-migrations.md) 自动升级上一版本，
基线之前的版本与未知版本明确拒绝。应用数据库由升级链逐版本升级，见
[应用数据库升级与本地 Debug 维护](debug-database-maintenance.md)。

正文按内容哈希保存；当前实体与不可变历史共享正文。库级互斥内的一笔事务更新实体、前后镜像、切块、FTS、
向量待处理状态和内容头。移动保持文档身份，所有已有文档修改验证 `expectedRevision`。路径规范化、来源、
元信息、正文和输出预算从存储常量派生，调用方不复制同义边界。
精确编辑在分配结果前，按真实非重叠匹配次数校验替换后 UTF-8 字节数；乘加溢出或超过正文上限即拒绝，
不能先生成被重复替换放大的字符串再检查。多项编辑中的任一失败不发布先前候选内容、修订、历史或索引。

每次实际内容变更恰好追加一条历史，批量搬运亦然；无变化搬运不追加。永久历史不删除。还原只允许人工确认，
目标为精确存在的序号，零表示初始空内容；还原把当前与目标的差异追加为新变更，旧历史仍可读取和再次还原。
还原重新分配单调修订号，旧的乐观令牌不会因旧内容恢复而重新有效。历史摘要、条目与正文分开分页；
正文必须指定变更、文档身份及前后侧别，侧别不存在即报错，不以当前正文替代。

## 四工具与完整暴露链

| 工具 | 内容与边界 |
| --- | --- |
| `knowledge_list` | 省略库身份列本回合启用库；指定库后按逻辑路径、深度及不透明游标列目录和文档元信息 |
| `knowledge_read` | 精确库、文档身份或路径二选一及包含边界行窗口；不支持语料或切块目标 |
| `knowledge_search` | 多查询及授权库子集；每库按自身模式检索，返回当前文档身份、修订、引用行和明确部分失败 |
| `knowledge_write` | 创建、更新、精确编辑、移动、删除文档，创建或修改目录、删除空目录、搬运原生文本文件 |

四工具均为 `Ungoverned`；授权与会话启用仍在执行时校验，子执行仅继承项目与库身份上限。
无访问快照或无启用库不注册；全部库为仅浏览时不注册搜索；计划模式不注册写入且执行闸门拒绝持久副作用。
专职会话的两种工具档位均保留已启用知识库工具，详见 [专职会话](dedicated-sessions.md)。

参数 `sources` 仅用于搬运的原生路径数组；创建及更新使用 `provenance` 来源对象数组，避免轻量模型 Schema
把不同形状的联合投影丢失。搬运复用宿主原生文件路径、忽略、遍历、快照及编解码边界；逐文件报告二进制、
读取或预算失败，成功文件可独立提交。源文本经必要编码转换后原样进入正文，不经过模型输入输出。
未变来源不产生变更；变化来源递增修订并将旧摘要标记为待复核。搬运只刷新曾由同一来源文件搬运的文档；
目标路径已有其他文档时整批拒绝，须改用其他目标目录或带 `expectedRevision` 的更新。摘要键可为来源原样的
非 glob 路径、规范绝对路径或库内目标路径；一键指向多个来源或多键指向同一来源时拒绝。

写入与已发布状态完全相同（含同值更新、同文替换、原地移动、同说明目录）时不追加历史、不递增修订，
回执无变更序号；仅正文实际变化且未重新提供摘要时才把已提供摘要标记为待复核。

执行者的会话、回合和工具调用身份来自真实准备回执及宿主上下文，不从工具参数猜测。结果为英文紧凑 Markdown，
外部内容明确标为不可信资料。写入宿主仅附 `knowledge_write_v1` 最小回执，不附完整正文；详见
[工具结果投影](tool-result-presentation.md)。

## 模式、向量与服务寿命

| 模式 | 能力 |
| --- | --- |
| `browse` | 目录及读取，不参与搜索 |
| `bm25` | 本地 Jieba 全文搜索 |
| `vector` | 声明嵌入模型的向量搜索 |
| `hybrid` | 全文与向量排名融合，明确报告每项未就绪能力 |

模式与嵌入配置属于库，项目和会话不保存检索策略。模式切换创建可查询、可取消的持久作业。停用能力时保留
上次保存的嵌入路由、维度、批量设置及已有索引。停用向量时不发起新的向量检索或生成；重新启用同一向量空间时，
只补当前缺失的内容哈希。已建的全文索引在停用时继续随文档变更增量维护，切回时直接使用；首次启用或需要修复时才构建。
服务启动先安装嵌入执行器再恢复作业；每库一个合并唤醒工作者，写入、还原及人工重试均可唤醒。
任务按稳定身份查询，取消及重启不使迟到工作复活。错误显式报告，不改成其他检索模式。
内容写入、搬运、无变化来源观测及还原只排队，不解除人工暂停；明确模式变更、重建或人工重试才恢复工作。
工作器在保留批次及发布结果前复核应用库的持久取消意图，并协调每库暂停标记，覆盖两个数据库提交间的中断。
同一协调入口也承认已接受的明确排队或运行操作；启动恢复不能因旧暂停标记而卡住已确认的模式变更、重建或重试。

向量按内容哈希和语义空间寻址，当前切块决定可检索成员。空间指纹冻结实际供应商、端点、连接、模型、绑定、
能力（含输入模板）及执行修订、维度和距离；目录代次与展示名称不参与。模型未声明距离时库冻结余弦距离（与向量长度无关，
不依赖供应商是否归一化），不因此隐藏或拒绝该模型。更换空间时新空间全部就绪后才切换，已有查询持有旧空间
租约直到结束。失败按唯一重试上限停止，人工可重试全部当前失败项或精确文档；不重置已就绪工作。

库身份随嵌入请求传递；内部配置档按实际库与冻结空间派生，套件无权指定其他库消费方。
OpenVulcan 向量适配器在发送时将知识库配置档映射为符合远端格式的稳定摘要标识。本地路由授权、配置档及向量空间仍使用完整身份。
执行器对服务持弱引用，删除清理与配置创建共用权威事务，防止延迟工作复活已删库。

## 套件

当前套件仅含严格清单及当前目录、文档 JSONL；当前模式所需配置与自定义词典可移植，停用的嵌入配置、历史、向量、数据库和本地实体身份不可移植。
有界检查归档条目、解压预算、完整文件指纹、内容摘要、实体及计数，全部成功后才建库。
导出在同一内容快照下原子落盘；预检返回完整文件 SHA-256，确认导入必须携带该指纹。
人工只可修改新库名称，不能覆盖已有库。导入建立不带项目授权的独立库，单条 `import` 开始新历史，向量重新生成。

## WebUI 与 TUI

WebUI 左侧快捷栏默认固定「知识库」，点击进入现有的知识库管理页。用户可通过「显示在侧栏」调整，已保存的布局优先。

两端按需读取逻辑目录，使用服务游标；当前和历史正文使用不同精确接口并按返回 `nextLine` 续读。
搜索的 `summary` 切块描述整篇文档，`0–0` 是无正文定位的标记。两端显示「摘要」并从正文首页打开，
AI 搜索结果提示按文档读取时省略行范围。WebUI 的正文切块仍从实际命中行打开，切换到原文可查看行高亮。
历史摘要以最后实际显示序号续读，详情与向量失败页使用服务 `nextOffset`，不假定序号连续。
WebUI 的当前与历史正文默认使用会话 Markdown 预览，同一个渲染器识别当前页内完整闭合的 `ui-*` 围栏，
例如可切换的标签页和可展开的详情。原文模式保留。TUI 以共享只读正文行保留缩进与空行。

作业、完整性、向量状态分开显示。轮询等待上一次读取结束；失败、暂停或终态停止对应轮询。
未知或读取失败的任务状态不授权取消或启动任务。成功变更后刷新权威读取，刷新失败只允许重读，不重放已提交变更。
内容头或设置改变撤销旧搜索结果，不自动重发付费查询。会话库选择使用实际已有会话与所属项目，不猜测草稿归属。
已创建专职会话的知识库选择保持冻结；TUI 按工作台权威种类标记只读展示当前有效选择，不派发继承或库开关变更。

TUI 的完整 RPC 对照见 [服务适配](tui-service-adaptation.md)；模拟状态与回环 HTTP 只证明界面和传输行为，
不证明真实供应商、向量质量或已运行宿主的端到端接受。验收须分别记录存储、服务、暴露链、两端测试和真实运行范围。

Vulcan Code 0.1.25 改进了桌面启动、知识库和专职助手。独立安装器 0.2.13 新增下载线路选择。

### 启动与运行时

```ui-checklist
ok | 桌面启动进度 | 启动界面显示 Core 当前阶段。下载技能时会显示正在下载的技能。
ok | LuaSkills 兼容性 | Core 使用随包 Lua 运行时和模块路径，避免系统 Lua 环境变量干扰。修复 Windows 中文等非 ASCII 安装路径下的 Lua 模块加载。
```

### 知识库

```ui-checklist
ok | 复用索引 | 切换检索模式会保留已有索引和嵌入配置。重新启用同一向量空间时，只补缺失的内容。
ok | 预览与搜索定位 | 网页端的正文和历史默认显示 Markdown 预览，可切换到原文。搜索摘要打开文档首页，正文命中仍跳到对应行。
```

### 助手与模型

```ui-checklist
ok | 记忆锁定 | 转换为浮动助手后立即打开浮窗并显示锁定状态。锁定期间完成的回合会提示其内容不会带入下一轮。
ok | 系统提示词 | 修改基础系统提示词后，下次执行就会在发送历史之前使用新指令，无需刷新会话。
```

### 独立安装器 0.2.13

```ui-checklist
ok | 下载线路 | 安装或更新时可选自动、国际或中国大陆线路。安装器会记住选择，命令行也可用 `--route` 指定。
```

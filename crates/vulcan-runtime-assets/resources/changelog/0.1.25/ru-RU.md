Vulcan Code 0.1.25 улучшает запуск настольного приложения, базы знаний и специализированные помощники. Автономный установщик 0.2.13 позволяет выбрать источник загрузки.

### Запуск и среда выполнения

```ui-checklist
ok | Ход запуска | На экране запуска виден текущий этап Core и название загружаемого навыка.
ok | Совместимость с LuaSkills | Core использует встроенную среду Lua и её пути к модулям, изолируя их от унаследованных переменных окружения. Исправлена загрузка модулей из путей установки Windows с символами вне ASCII.
```

### Базы знаний

```ui-checklist
ok | Повторное использование индексов | При смене режима поиска сохраняются индексы и настройки эмбеддингов. При повторном включении того же векторного пространства обрабатываются только отсутствующие данные.
ok | Просмотр и поиск | В веб-приложении текущие и предыдущие версии документов открываются в режиме предпросмотра Markdown с возможностью перейти к исходному тексту. Сводка ведёт к началу документа, а совпадение в тексте — к нужной строке.
```

### Помощники и модели

```ui-checklist
ok | Блокировка памяти | После преобразования открывается плавающий помощник и показывает состояние блокировки. Для ходов, завершённых при блокировке, выводится уведомление, что их содержимое не попадёт в следующий ход.
ok | Системные инструкции | Изменения базовых системных инструкций применяются перед историей при следующем запуске без обновления сеанса.
```

### Автономный установщик 0.2.13

```ui-checklist
ok | Источники загрузки | При установке и обновлении доступны автоматический выбор, международный источник и источник для материкового Китая. Выбор сохраняется. Его также можно задать через `--route`.
```

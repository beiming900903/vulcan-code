Vulcan Code 0.1.25 では、デスクトップの起動、ナレッジベース、専用アシスタントを改善しました。単体インストーラー 0.2.13 ではダウンロード経路を選べます。

### 起動とランタイム

```ui-checklist
ok | デスクトップの起動状況 | 起動画面に Core の現在の段階と、ダウンロード中のスキル名が表示されます。
ok | LuaSkills の互換性 | Core は同梱の Lua ランタイムとモジュールパスを使用し、継承した環境変数による干渉を防ぎます。日本語などの非 ASCII 文字を含む Windows のインストール先でもモジュールを読み込めます。
```

### ナレッジベース

```ui-checklist
ok | インデックスの再利用 | 検索モードを切り替えてもインデックスと埋め込み設定が保持されます。同じベクトル空間を再び有効にすると、不足分だけが補われます。
ok | プレビューと検索結果 | Web 版では現在および過去の文書を Markdown でプレビューでき、原文にも切り替えられます。概要からは文書の先頭へ、本文の一致箇所からは該当行へ移動します。
```

### アシスタントとモデル

```ui-checklist
ok | メモリのロック | 変換後にフローティングアシスタントが開き、ロック状態を表示します。ロック中に完了したターンには、次のターンへ引き継がれないことが表示されます。
ok | システムプロンプト | 基本システムプロンプトの変更は、セッションを更新しなくても次の実行で履歴より先に適用されます。
```

### 単体インストーラー 0.2.13

```ui-checklist
ok | ダウンロード経路 | インストール・更新時に自動、国際、中国大陸から選べます。選択は保存され、`--route` でも指定できます。
```

Vulcan Code 0.1.25 改善了桌面啟動、知識庫及專職助手。獨立安裝程式 0.2.13 新增下載線路選擇。

### 啟動與執行環境

```ui-checklist
ok | 桌面啟動進度 | 啟動畫面會顯示 Core 目前的階段及正在下載的技能。
ok | LuaSkills 兼容性 | Core 使用隨附的 Lua 執行環境及模組路徑，避免系統 Lua 環境變數干擾，並修正 Windows 在含中文等非 ASCII 字元的路徑載入模組的問題。
```

### 知識庫

```ui-checklist
ok | 重用索引 | 切換檢索模式時保留既有索引及嵌入設定。重新啟用同一向量空間時，只補齊缺少的內容。
ok | 預覽及搜尋定位 | 網頁版的正文和歷史預設使用 Markdown 預覽，可切換至原文。搜尋摘要開啟文件首頁，正文命中會跳到相應行。
```

### 助手與模型

```ui-checklist
ok | 記憶鎖定 | 轉換為浮動助手後會開啟視窗並顯示鎖定狀態。鎖定期間完成的回合會提示內容不會帶入下一回合。
ok | 系統提示詞 | 修改基礎系統提示詞後，下次執行會先使用新指令再傳送歷史，毋須重新整理對話。
```

### 獨立安裝程式 0.2.13

```ui-checklist
ok | 下載線路 | 安裝或更新時可選自動、國際或中國內地線路。安裝程式會記住選擇，亦可用 `--route` 指定。
```

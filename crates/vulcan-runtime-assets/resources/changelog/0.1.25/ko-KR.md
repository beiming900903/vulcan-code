Vulcan Code 0.1.25는 데스크톱 시작 화면, 지식 베이스, 전용 어시스턴트를 개선했습니다. 독립 설치 프로그램 0.2.13에서는 다운로드 경로를 선택할 수 있습니다.

### 시작 및 런타임

```ui-checklist
ok | 데스크톱 시작 진행률 | 시작 화면에 Core의 현재 단계와 다운로드 중인 스킬 이름이 표시됩니다.
ok | LuaSkills 호환성 | Core는 기본 제공 Lua 런타임과 모듈 경로를 사용해 상속된 환경 변수의 영향을 피합니다. 한글 등 ASCII 이외의 문자가 포함된 Windows 설치 경로에서도 모듈을 로드할 수 있습니다.
```

### 지식 베이스

```ui-checklist
ok | 인덱스 재사용 | 검색 모드를 바꿔도 기존 인덱스와 임베딩 설정이 유지됩니다. 같은 벡터 공간을 다시 활성화하면 누락된 내용만 보충합니다.
ok | 문서 미리 보기와 검색 | 웹에서 현재 문서와 이전 버전을 Markdown으로 미리 보고 원문으로 전환할 수 있습니다. 요약 결과는 문서 처음으로, 본문 결과는 일치하는 줄로 이동합니다.
```

### 어시스턴트 및 모델

```ui-checklist
ok | 메모리 잠금 | 전환 후 플로팅 어시스턴트 창이 열리고 메모리 잠금 상태가 표시됩니다. 잠금 중 끝난 턴에는 다음 턴으로 이어지지 않는다는 안내가 표시됩니다.
ok | 시스템 프롬프트 | 기본 시스템 프롬프트를 수정하면 세션을 새로 고치지 않아도 다음 실행에서 대화 기록보다 먼저 반영됩니다.
```

### 독립 설치 프로그램 0.2.13

```ui-checklist
ok | 다운로드 경로 | 설치하거나 업데이트할 때 자동, 국제, 중국 본토를 선택할 수 있습니다. 선택은 저장되며 `--route`로도 지정할 수 있습니다.
```
